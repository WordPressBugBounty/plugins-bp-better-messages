== Description ==

**Better Messages** is the most feature-rich **realtime private messaging system for WordPress**, with native integrations for **BuddyPress, BuddyBoss Platform, Ultimate Member, PeepSo** and any other WordPress powered websites.

Transform your WordPress site into a powerful communication platform with **private messaging**, **chat rooms**, **video and audio calls**, **group video calls with recording**, **AI chat bots**, and **native mobile apps**.

Whether you're building a private or public community, social network, intranet, chat-rooms site, marketplace, membership site, dating platform, or creator economy site – Better Messages provides enterprise-level messaging features with an easy-to-use interface.

== Frequently Asked Questions ==

= Is Better Messages free? =

Yes — install the free version from WordPress.org. It supports private and group conversations, chat rooms, file sharing, oEmbed previews, smart-batched email notifications, role-based access, guest chat, polls, spam protection, chat for bookings, and the standard messenger feature set. The WebSocket version is paid and unlocks instant delivery, one-on-one and group voice / video calls with backgrounds, noise removal and recording, Better Messages Cloud AI (content moderation, message translation and voice message transcription with no API key of your own), web push, end-to-end encryption, and your own iOS and Android apps.

= Which WordPress plugins does Better Messages integrate with? =

40+ native integrations across community platforms (BuddyPress, BuddyBoss Platform, PeepSo, Ultimate Member, FluentCommunity, SureDash, ProfileGrid, UsersWP, WP User Manager), LMS (LearnDash, LearnPress, Tutor LMS, MasterStudy LMS), e-commerce (WooCommerce — pre-sales and order support chat with contact buttons on product, cart, checkout, and order pages), multi-vendor marketplaces (Dokan, WCFM, WC Vendors, MultiVendorX), listings and directories (HivePress, Directorist, GeoDirectory, Classified Listing, Motors, WP Job Manager), bookings (Amelia, LatePoint, FluentBooking, Simply Schedule Appointments), real estate themes (Houzez, RealHomes), forums (wpForo, bbPress), gamification (GamiPress, MyCRED), automation (Uncanny Automator, AutomatorWP), page builders (Crocoblock JetEngine), push / PWA (FluentNotify, OneSignal, Progressify), and multilingual sites (GTranslate, Weglot). If your plugin isn't listed, the built-in visual Shortcode Builder lets you add a Live Chat Button to any custom post type without writing PHP. See the [full list of integrations](https://www.better-messages.com/docs/category/integrations/).

= Does it support group conversations? =

Yes — first-class group chats with shared history, mentions, reactions, file uploads, replies, edit / delete / forward, and group voice / video calls (WebSocket version). Group chats can be auto-paired with BuddyPress / BuddyBoss / PeepSo / Ultimate Member / FluentCommunity groups, with members joining and leaving the chat in sync with the source community group.

= Can unregistered visitors (guests) chat? =

Yes — Guest Chat lets unregistered visitors join chat rooms, message vendors on marketplaces, ask questions on directory listings, chat about a booking, or chat with site support. Guests fill in a sign-up form that can ask for a name and an email and can be protected by a captcha, then participate as a guest user. A guest with a confirmed email signs in again on another device with a link sent to it, and a guest who registers later is asked to move the conversations into the account.

= Does it support voice and video calls on WordPress? =

Yes (WebSocket version) — one-on-one and group voice / video calls live inside the messenger thread, not as a separate Zoom / Whereby integration. Hosted media relay is included with the WebSocket license, no separate Twilio account, no Daily / Whereby subscription, no Zoom developer plan. There is no limit on people in a group call: each site includes 32 people on video or 50 on audio at once across its group calls, plus 5,000 WordPlus Cloud credits every month for more. Calls have device settings, background blur and virtual backgrounds, AI noise removal, screen sharing, host controls and picture in picture, and group calls can be recorded with a transcript.

= Is Better Messages GDPR-compatible? =

Yes. All message data is stored only in your WordPress database. The WebSocket cloud relay is blind to message content — it routes encrypted events and keeps only the last few minutes of each conversation, still encrypted, but cannot read or inspect what passes through. Better Messages also integrates with WordPress's built-in Personal Data Export and Erasure tools. Call recordings, when an administrator turns them on, are kept on your site or in your own cloud storage. For sites with stricter data-sovereignty requirements (GDPR Article 9, HIPAA-adjacent, regulated-data workloads), a self-hosted plan is available — contact support.

= Does it have AI features? =

Yes. AI Chat Bots (OpenAI, Anthropic Claude, Google Gemini) work in the free version with your own provider API key. They act as full participants in any thread, with custom system prompts and per-bot points charging via GamiPress / MyCRED. Better Messages Cloud AI (WebSocket version) provides AI Content Moderation (23+ categories including spam, scam, doxxing, contact sharing), AI Message Translation (53 languages with auto-detection), and Voice Message Transcription (99+ languages) — all included with the WebSocket license, no third-party API key required.

= Does it have native iOS and Android apps? =

Yes (WebSocket version) — Better Messages makes native iOS and Android apps for your site, on Capacitor, with push notifications, real-time delivery, native voice / video call screens, website sign-in with your two-factor authentication, an app lock with Face ID or the fingerprint, and the messenger's features. You build your branded app from WP Admin and publish it on the App Store / Play Store under your own developer accounts.

= Can I translate the messenger interface to my language? =

Yes — Better Messages is fully translatable through standard WordPress translation tools (Loco Translate, WPML, Polylang) using the `bp-better-messages` text domain. Ships with 30+ community translations. Contribute or improve a translation at [translate.wordpress.org](https://translate.wordpress.org/projects/wp-plugins/bp-better-messages/).

= Does it support end-to-end encryption? =

Yes (WebSocket version). End-to-end encryption is enabled per thread — messages and file attachments are encrypted in the sender's browser with AES-256-GCM before transmission, stay encrypted at rest in the database, and decrypt only in the recipient's browser. The server stores ciphertext only, no admin, host engineer, or attacker with database access can read the message content of an E2E thread.

= Does it protect against spam? =

Yes, in the free version too. Spam Protection under **Settings → Moderation** has a level (Monitor only, Balanced, Strict or Custom) that flags, holds for a moderator or refuses what accounts behaving like spammers send, with tighter limits for new accounts and guests. Email addresses, phone numbers and messenger usernames in messages can be hidden, held or refused, first messages from strangers can wait as message requests until the member accepts them, and the Review tab under Administration gathers the reported, flagged and held messages and the accounts under review, with Mark as spammer. A site updated from an older version starts at Monitor only, which changes nothing and shows what would have been stopped.

= Does it work with booking plugins? =

Yes. Each booking of Amelia, LatePoint, FluentBooking and Simply Schedule Appointments gets a conversation between the customer and the staff member, opened from the Message button or from the link in the booking emails, with a card that shows the service, the time and the status and follows the booking when it is moved or cancelled. A customer who booked without an account chats as a guest. In the WebSocket version the video call of a booking opens for the customer shortly before the appointment.

= Does it have polls? =

Yes, in the free version too. Members make a poll from the attachment menu of a conversation and everyone votes on its card. A poll can be anonymous, allow multiple answers, be a quiz with a right answer, or end at a time you choose. **Settings → Polls** chooses the kinds of conversations and the roles that can make polls.

= Can it encrypt what is stored in my database? =

Yes (WebSocket version). **Settings → Messaging → Stored Data Encryption** creates a key in wp-config.php and keeps messages, conversation names, files, and the email and IP address of guests encrypted in the database and the uploads folder, so a copy of the database cannot be read without the key. It is separate from end-to-end encryption: the site still shows the messages to moderators, and search still finds whole words.

= Which external services does Better Messages connect to? =

The plugin connects to WordPlus Cloud, the plugin author's service that sells and licenses the WebSocket version, only when an administrator uses one of these features:

* **Plans, prices and reviews.** When an administrator opens Better Messages → Upgrade, the site asks WordPlus Cloud (api.wordplus.cloud) for the current plans, prices and customer reviews, and keeps the answer for an hour. No personal data is sent, only the request itself, which WordPress makes with the site's address. The administrator's browser then loads the reviews' photos from WordPlus Cloud.
* **Contact form.** When an administrator sends a message from Better Messages → Support, the plugin sends what they wrote, their name and email address, any files they attach, any access details they choose to share, and the site's address and technical details (the WordPress, PHP, database and web server versions, the theme and the active plugins), which the form shows before sending.
* **Better Messages Assistant, only after you press Start.** The AI assistant on Better Messages → Support sends nothing until an administrator presses Start under the list of what it sends. Start registers the site with WordPlus Cloud (its address, the plugin version and whether it is the free or the WebSocket version). Then each question goes to WordPlus Cloud's assistant service (rest.wordplus.cloud) with the site's address, the plugin's settings (without keys or passwords), the plugin, WordPress, PHP and theme versions, the active plugins and the administrator's language, and the answer comes back to the page. Questions and answers are stored and read by the plugin's team to improve the assistant. Visitors' data is never sent. "Turn off the assistant" under the chat stops it, and the `wordplus_sdk_assistant_enabled` filter hides it.
* **Buying.** Buying happens on the WordPlus Cloud website (www.wordplus.cloud), never inside WordPress. The Upgrade buttons open it with the site's address. After paying, the plugin sends WordPlus Cloud the one-time code it came back with, the site's address, the plugin version and a random identifier of the site, and gets the licence key.
* **Installing the WebSocket version, only when asked for.** If the buyer asks for it on the WordPlus Cloud checkout page, WordPlus Cloud contacts the site, and the site downloads the WebSocket version from WordPlus Cloud and installs it. Nothing is installed unless the buyer asks on that page.
* **Licence check.** Once a licence key is saved, the site sends the key, its address and the plugin version to WordPlus Cloud once a day to confirm the licence.
* **Emoji and sticker downloads, only when an administrator asks.** "Download emoji images to your server", the emoji names in other languages and the sticker packs come from WordPlus Cloud's CDN (cdn.wordplus.cloud), or from WordPlus Cloud (api.wordplus.cloud) when the CDN fails, and the sticker settings ask it for the list of packs when they open. The administrator's browser loads the packs' cover pictures from the same addresses. These requests send the plugin's name and version, and WordPress adds the site's address to every request it makes.
* **Usage data, only if you opt in.** After the plugin is first activated, it asks once whether to share usage data, and nothing is sent unless an administrator chooses Allow & Continue. Then the site sends the administrator's name and email address (to tell them about security and feature updates), the site's address, title, language and time zone, the WordPress, PHP and plugin versions and whether the plugin is active, and, unless switched off, which of the plugin's features and settings are in use (on/off values, numbers and short setting values, never your content, addresses or keys, and the size of the site's messaging only as a range) and the names and versions of its plugins and themes. With them goes how far the setup in Get started has come (which of its cards are done or dismissed), and when the free trial notice was shown and which of its buttons was clicked. It sends them once a day when something changed, and when the plugin is activated, deactivated or deleted. The newsletter is a separate choice, off unless switched on. Each choice can be changed, or the sharing stopped, from the Opt out link under the plugin on the Plugins screen. Opting out has WordPlus Cloud erase what was shared. A site that opted in through Freemius in an earlier version stays opted in, and its administrators are told once that its data goes to WordPlus Cloud now. Only the WebSocket version adds the features and settings in use to what such a site shares, unless switched off. The free version shares them only once an administrator switches them on. A site that skipped Freemius's opt-in is not asked again.
* **AI model prices, only when an administrator asks, or with a licence.** The AI chat bots count what their answers cost by a price list of the AI models that comes with the plugin. **Check for new prices** in **Settings → Integrations → AI Services** asks WordPlus Cloud for a newer list, from its CDN (cdn.wordplus.cloud) or from WordPlus Cloud (api.wordplus.cloud) when the CDN fails, and a site with an active WebSocket licence asks once a week, after its licence check. The request sends the version of the WordPlus code in the plugin, and WordPress adds the address of the site to every request it makes. Only the list comes back, which the site reads as prices and nothing else.
* **Deactivation feedback, only when you send it.** When the plugin is deactivated, it may ask why. The answer is sent to WordPlus Cloud only if the administrator submits it, without their email or the site's address unless they opted in to usage data and left "Anonymous feedback" unticked.

The WebSocket version, which WordPlus Cloud sells and which is not on WordPress.org, also connects to WordPlus Cloud for these:

* **Realtime delivery and calls.** Messages, typing, online statuses and call signals go through WordPlus Cloud's realtime servers (ws.wordplus.cloud, rest.wordplus.cloud), encrypted with keys only the site gives out, and calls through its call servers (*.rtc.wordplus.cloud). Better Messages Cloud AI, where an administrator switches it on, sends the message or voice message it moderates, translates or transcribes, and keeps nothing. The licence status at the top of the settings shows the WordPlus Cloud credits of the site's account, which group calls above the 32 people a site includes and call recordings use.
* **Video effects, only when an administrator downloads them.** **Settings → Calls → Video Effects** downloads the background effects and AI Noise Removal from WordPlus Cloud's CDN (cdn.wordplus.cloud), or from WordPlus Cloud (api.wordplus.cloud) when the CDN fails, and reads its catalog of built-in backgrounds there, downloading the pictures an administrator picks. The administrator's browser loads the catalog's thumbnails from the same addresses. After an update of the plugin, a site that downloaded them gets the newer files the same way. Calls then load the effects and backgrounds from the site itself. WordPress adds the address of the site to every request it makes.
* **Call recording, only when an administrator turns it on.** With **Record Group Calls** on, a moderator's Record has WordPlus Cloud's recorder join that group call: it receives the call's sound, video and shared screens, with the names and profile pictures of the people in it, makes the recording and, unless switched off, its transcript, and puts the files into the site's cloud storage, or keeps them until the site downloads them, for seven days at most. Each minute recorded takes a WordPlus Cloud credit.

WordPlus Cloud: [terms of service](https://www.wordplus.cloud/terms), [privacy policy](https://www.wordplus.cloud/privacy).

= Which other services can Better Messages use? =

Besides WordPlus Cloud, the plugin uses these services, each as described:

* **Emoji images (jsDelivr).** Emoji show as Apple's images by default, and until the site downloads them, browsers load the image sheet from jsDelivr (cdn.jsdelivr.net), which receives the visitor's IP address. "Download emoji images to your server" in the emoji settings, or the native emoji set, stops it. jsDelivr: [terms of service](https://www.jsdelivr.com/terms), [privacy policy](https://www.jsdelivr.com/terms/privacy-policy-jsdelivr-net).
* **Video and media links (YouTube, Vimeo and other oEmbed providers).** With oEmbeds on, which is the default, a link to a provider WordPress's oEmbed support knows makes the site ask that provider for its player, and the player loads from the provider in the conversation. With "Privacy-friendly oEmbeds" on, a video loads only after a click. YouTube: [terms of service](https://www.youtube.com/t/terms), [Google privacy policy](https://policies.google.com/privacy). Vimeo: [terms of service](https://vimeo.com/terms), [privacy policy](https://vimeo.com/privacy).
* **GIFs (GIPHY, KLIPY), only with your own API key.** Searches typed in the GIF picker go from the site to the chosen provider, with a random identifier for each member and never their name, and GIFs load in browsers from the provider's servers. GIPHY: [terms of service](https://giphy.com/terms), [privacy policy](https://giphy.com/privacy). KLIPY: [API terms](https://klipy.com/support/api-terms), [privacy policy](https://klipy.com/support/privacy-policy).
* **Stipop stickers, only with your own API key.** The sticker store and sticker searches go to Stipop (messenger.stipop.io) with the member's numeric ID on the site and the chosen language, and the stickers load in browsers from img.stipop.io. Stipop: [terms of service](https://stipop.io/en/policies/terms), [privacy policy](https://stipop.io/en/policies/privacy).
* **AI chat bots and AI features, only with your own API key.** With an OpenAI, Anthropic or Google Gemini key, the messages of conversations with an AI bot, with the bot's instructions, and the content an AI feature works on (messages it checks, voice messages it transcribes) go to that provider. OpenAI: [terms of use](https://openai.com/policies/terms-of-use), [privacy policy](https://openai.com/policies/privacy-policy). Anthropic: [commercial terms](https://www.anthropic.com/legal/commercial-terms), [privacy policy](https://www.anthropic.com/legal/privacy). Google Gemini: [API terms](https://ai.google.dev/gemini-api/terms), [privacy policy](https://policies.google.com/privacy).
* **Location sharing, only when switched on.** Browsers showing a shared place load the map from tile.openstreetmap.org, and the place search and nearby places send the search text or the map's position to nominatim.openstreetmap.org and overpass-api.de. These addresses can be changed in the location settings. OpenStreetMap: [tile usage policy](https://operations.osmfoundation.org/policies/tiles/), [Nominatim usage policy](https://operations.osmfoundation.org/policies/nominatim/), [privacy policy](https://osmfoundation.org/wiki/Privacy_Policy). Overpass API: [terms](https://dev.overpass-api.de/overpass-doc/en/preface/commons.html).
* **OneSignal, only with the OneSignal plugin.** When the OneSignal integration is used, the site links each member's push subscription to their numeric ID on the site at OneSignal (api.onesignal.com), so message notifications reach them. OneSignal: [terms of service](https://onesignal.com/tos), [privacy policy](https://onesignal.com/privacy_policy).
* **Cloud storage, only when connected.** With a storage provider connected (Amazon S3, Cloudflare R2 or another S3-compatible service), files sent in messages are kept with that provider in the administrator's own account, and browsers upload and download them there. The provider's own terms and privacy policy apply.
* **Mobile App, only when an administrator sets one up.** On Better Messages → Mobile App, the Android signing key and its passwords are sent to the plugin author's app builder (builder.better-messages.com) to check or create them, and the Apple and Google keys the administrator enters are checked with Apple (api.appstoreconnect.apple.com) and Google. Apple: [privacy policy](https://www.apple.com/legal/privacy/). Google Firebase: [terms](https://firebase.google.com/terms), [privacy policy](https://policies.google.com/privacy).
* **FFmpeg, only when downloaded.** "FFmpeg WASM (~30 MB)" in the media settings downloads the video converter once from better-messages.com to the site, which then serves it to the browsers that convert videos before sending them.
